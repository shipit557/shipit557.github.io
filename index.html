Reasonably Technical Analytics

A private tool used only by the owner of the Reasonably Technical YouTube channel (@reasonablytech) to read that channel's own analytics. It is not offered to the public.

Privacy Policy

Last updated: November 9, 2026

What it accesses. Read-only access to the owner's own channel analytics and video details through the YouTube Analytics API and YouTube Data API (scopes: yt-analytics.readonly, youtube.readonly). It cannot upload, edit, or delete anything.

How data is used. Reports are saved on the owner's computer and used to plan and improve the channel's videos, including with AI assistants the owner uses for research and editing. Data is not sold, used for advertising, or shared with anyone else.

Storage and removal. Sign-in tokens and reports are stored locally. Access can be revoked at any time at myaccount.google.com/permissions, and deleting the local files removes the stored data.

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
